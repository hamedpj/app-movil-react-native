# 📱 SupplyChain Marine-Pro – Logistics Management App

Cross-platform mobile application (Android/iOS) developed with **React Native (Expo)**. Designed to digitize and optimize the maritime supply chain for shipping companies, covering the entire workflow from order reception to final delivery and automated invoicing.

---

## 🚀 Technologies Used

- React Native (Expo)
- JavaScript / ES6+
- React Navigation (Stack & Tab navigators)
- Google Maps API (Real-time ship location tracking)
- Camera integration (Delivery photo evidence)

---

## 📋 Key Features

- ✅ **Multi-role system:** Admin, Logistics Chief, and Employee with distinct permission flows and navigation stacks.
- ✅ **Complete logistics workflow:** Centralized dashboard, purchase checklist, real-time delivery tracking, and photo evidence uploads.
- ✅ **Financial module:** Automatic PDF invoice generation, profit margin calculations, and sales/gains summaries per client.
- ✅ **Real-time location tracking:** Integration with Google Maps to monitor ship status (docked or in motion).
- ✅ **Hardware integration:** Device camera used to capture proof of delivery.

## 🛠️ How to Run Locally

1. Clone this repository.
2. Run `npm install` to install dependencies.
3. Run `npx expo start` to launch the development server.
4. Scan the QR code with the Expo Go app (Android) or use the iOS simulator.
